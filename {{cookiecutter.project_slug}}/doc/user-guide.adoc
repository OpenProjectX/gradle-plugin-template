== Overview

`{{ cookiecutter.project_slug }}` is a Gradle plugin: {{ cookiecutter.description }}.

The project is organised as a multi-module build:

* `core` — reusable Kotlin library code shared by both plugins.
* `plugin` — the Gradle plugin implementation, built with `java-gradle-plugin` and verified with Gradle TestKit functional tests.
* `maven-plugin` — a Maven plugin (Mojo) that reuses the same `core` logic, with its descriptor generated by the `org.gradlex.maven-plugin-development` Gradle plugin.
* `examples/basic` — a composite-build example that applies the plugin via `includeBuild("../..")`.

== Requirements

* Java {{ cookiecutter.java_version }} or later
* Gradle 8.x or later (the build ships a wrapper)

== Applying the Plugin

Add the plugin to the `plugins` block of your build script.

.build.gradle.kts
[source,kotlin,subs="+attributes"]
----
plugins {
    id("{{ cookiecutter.plugin_id }}") version "0.1.0"
}
----

.build.gradle (Groovy)
[source,groovy,subs="+attributes"]
----
plugins {
    id "{{ cookiecutter.plugin_id }}" version "0.1.0"
}
----

== Using the Maven Plugin

The same core logic is also published as a Maven plugin from the `maven-plugin` module. Run
its `say-hello` goal directly:

[source,bash,subs="+attributes"]
----
mvn {{ cookiecutter.extension_name }}:say-hello
----

Or bind it to a lifecycle phase in your `pom.xml`:

.pom.xml
[source,xml,subs="+attributes"]
----
<plugin>
    <groupId>{{ cookiecutter.group_id }}</groupId>
    <artifactId>maven-plugin</artifactId>
    <version>0.1.0</version>
    <executions>
        <execution>
            <goals>
                <goal>say-hello</goal>
            </goals>
        </execution>
    </executions>
</plugin>
----

The goal accepts a `{{ cookiecutter.extension_name }}.message` property (and `{{ cookiecutter.extension_name }}.skip` to disable it).

== Configuration

The plugin registers the `{{ cookiecutter.extension_name }}` extension, which you can use to configure its behaviour.

.build.gradle.kts
[source,kotlin]
----
{{ cookiecutter.extension_name }} {
    // Configure the plugin here.
}
----

== Tasks

[cols="1,3",options="header"]
|===
| Task | Description

| `build`
| Assembles and tests the project.

| `test`
| Runs the unit and Gradle TestKit functional tests.

| `asciidoctor`
| Generates this HTML documentation from the AsciiDoc sources under `doc/`.
|===

== Building From Source

[source,bash]
----
./gradlew build
----

Run the documentation build:

[source,bash]
----
./gradlew asciidoctor
----

The rendered HTML is written to `build/docs`, with `index.html` as the entry point.

== Releasing

Releases are driven by the `net.researchgate.release` plugin and publish to Maven Central
via the Sonatype Nexus publish plugin. See the project `README` and the GitHub Actions
workflows under `.github/workflows` for the automated release and documentation pipelines.
